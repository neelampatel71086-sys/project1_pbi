🚀 Project Overview

Welcome to my Superstore Sales Analysis Dashboard, a Power BI project designed to transform raw sales data into meaningful business insights through data cleaning, interactive visualizations, and professional dashboard design.

The project uses the Superstore Sales dataset to explore sales performance, profitability, product categories, regional performance, and customer segments. It demonstrates how Power BI can turn complex datasets into clear, interactive, and visually appealing reports that support better business decisions.

🎯 My Goal: To build an interactive dashboard that presents key business performance indicators in a simple, organized, and professional format.


---

🎯 Project Objectives

📥 Connect Power BI Desktop to the Superstore Sales dataset.

🧹 Clean and transform data using Power Query Editor.

🔍 Explore columns, data types, data quality, and applied steps.

📈 Create KPI cards to highlight important business metrics.

📊 Build charts to analyze sales, profit, categories, and regions.

🎛️ Add slicers and filters for interactive data exploration.

🧹 Project Workflow

1️⃣ Data Connection & Exploration

Connected the Superstore Sales dataset to Power BI Desktop and explored the available tables and columns.

2️⃣ Data Cleaning & Transformation

Used Power Query Editor to prepare the dataset for analysis.

Key activities included:

Renaming columns for better readability.

Correcting data types for dates and numerical fields.

Checking and removing null values in important columns.

Filtering the dataset to retain Consumer and Corporate segments.

Splitting the Order ID column using a delimiter.

Removing unnecessary columns such as Row ID, Country, and Postal Code.


3️⃣ KPI Cards

Created KPI cards to highlight the most important business metrics:

💰 Total Sales

📈 Total Profit

📦 Total Quantity

🏷️ Average Discount


These indicators provide a quick overview of overall business performance.

4️⃣ Data Visualization

Designed charts to explore sales performance across different dimensions, including product categories, regions, and sub-categories.

The visuals help users identify patterns, compare performance, and understand how different parts of the business contribute to the overall results.

5️⃣ Interactive Slicers & Filters

Added interactive controls to make the dashboard more useful.

Region Slicer: Explore performance by region.

Category Slicer: Focus on specific product categories.

Page-Level Filter: Include Standard Class and Second Class shipping modes.

Visual-Level Filter: Display the top five sub-categories by sales in a selected bar chart.


6️⃣ Dashboard Formatting

Applied professional formatting to improve readability and presentation.

Used meaningful titles for every visual.

Applied a consistent red and charcoal colour palette.

Enabled data labels on charts.

Formatted KPI values for better visibility.

Added a subtitle to provide context.

Removed unnecessary gridlines.

Aligned visuals using gridlines and alignment guides.

Applied a professional Power BI theme.


7️⃣ Report Pages

Organized the report into two pages:

Page 1 — Sales Dashboard
An interactive overview of sales performance, profit, quantity, discounts, and visual comparisons.

Page 2 — Detailed Order Analysis
A table-based view of detailed order information for exploring individual records.

8️⃣ Visual Interactions

Configured cross-filtering and cross-highlighting so that selecting a data point in one visual can affect other relevant visuals.

This makes the report more interactive and helps users investigate relationships between categories, regions, and business performance.
